# ❄️ NeoFrio Refrigeração - Versão 2.0

Esta é a versão aprimorada do site institucional da **NeoFrio**. O projeto foi refatorado para oferecer uma experiência de usuário (UX) superior, com foco total em conversão de clientes e performance em dispositivos móveis na região de Belém/PA.

## 🛠️ O que há de novo na V2?
* **Refatoração do CSS:** Código mais limpo utilizando variáveis nativas para fácil manutenção de cores e fontes.
* **Hero Section Dinâmica:** Implementação de imagem de fundo com overlay (máscara de brilho) via CSS, garantindo legibilidade do texto.
* **Otimização para Mobile:** Ajustes finos de media queries para que o site funcione perfeitamente em telas pequenas.
* **Integração API WhatsApp:** Script personalizado para abertura direta de conversa com mensagem pré-definida.

## 🚀 Tecnologias Utilizadas
* **HTML5 Semântico:** Melhor indexação para motores de busca (SEO).
* **CSS3 Moderno:** Flexbox, Grid e posicionamento avançado para layout fluido.
* **JavaScript:** Manipulação de DOM para interatividade e automação de links.
* **Font Awesome:** Biblioteca de ícones para auxílio visual na navegação.

## 📋 Funcionalidades Principais
1. **Atendimento Direto:** Botão flutuante e botões de chamada rápida integrados ao WhatsApp.
2. **Seção de Diferenciais:** Destaque visual para Garantia, Rapidez e Limpeza.
3. **Cartões de Serviços:** Informações claras sobre Instalação, Higienização e Manutenção.
4. **Header Fixo:** Menu sempre acessível para facilitar a navegação.
